# wtype

`wtype` is a Wayland text copy-paste/typing utility. It is required by Voxtype to type transcriptions into active windows.

## Installation

*   **Debian/Ubuntu/gLinux**:
    ```bash
    sudo apt install wtype
    ```
*   **Arch Linux**:
    ```bash
    sudo pacman -S wtype
    ```
*   **Fedora**:
    ```bash
    sudo dnf install wtype
    ```
