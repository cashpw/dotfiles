# starship

`starship` is a minimal, fast, and infinitely customizable prompt for any shell.

## Installation

*   **Debian / gLinux (Work)**:
    ```bash
    sudo apt install starship
    ```
    *Or official install script:*
    ```bash
    curl -sS https://starship.rs/install.sh | sh
    ```
*   **Fedora (Personal)**:
    ```bash
    sudo dnf install starship
    ```
