# wl-copy (wl-clipboard)

`wl-copy` and `wl-paste` are command-line copy/paste utilities for Wayland, provided by the `wl-clipboard` package.

## Installation

*   **Debian / gLinux (Work)**:
    ```bash
    sudo apt install wl-clipboard
    ```
*   **Fedora (Personal)**:
    ```bash
    sudo dnf install wl-clipboard
    ```
