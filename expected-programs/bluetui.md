# bluetui

`bluetui` is a TUI utility for managing Bluetooth devices and connections. Configuration is located at `~/.config/bluetui/config.toml`.

## Installation

*   **Cargo (Debian / gLinux / Fedora)**:
    ```bash
    cargo install bluetui
    ```
*   **Fedora (Personal - if packaged)**:
    ```bash
    sudo dnf install bluetui
    ```
