# swayidle

`swayidle` is an idle management daemon for Wayland compositors.

## Installation

*   **Debian/Ubuntu/gLinux**:
    ```bash
    sudo apt install swayidle
    ```
*   **Fedora**:
    ```bash
    sudo dnf install swayidle
    ```
*   **Arch Linux**:
    ```bash
    sudo pacman -S swayidle
    ```
