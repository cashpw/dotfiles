# flatpak

`flatpak` is a utility for software deployment, package management, and application virtualization on Linux.

## Installation

*   **Debian / gLinux (Work)**:
    ```bash
    sudo apt install flatpak
    ```
*   **Fedora (Personal)**:
    ```bash
    sudo dnf install flatpak
    ```

## Add Flathub Repository

```bash
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
```
