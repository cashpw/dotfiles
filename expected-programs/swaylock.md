# swaylock

`swaylock` is a screen locking utility for Wayland compositors like Sway.

## Installation

*   **Debian/Ubuntu/gLinux**:
    ```bash
    sudo apt install swaylock
    ```
*   **Fedora**:
    ```bash
    sudo dnf install swaylock
    ```
*   **Arch Linux**:
    ```bash
    sudo pacman -S swaylock
    ```
