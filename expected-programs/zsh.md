# zsh

`zsh` (Z Shell) is an advanced shell used as the primary command-line interpreter in this environment.

## Installation

*   **Debian / gLinux (Work)**:
    ```bash
    sudo apt install zsh
    ```
*   **Fedora (Personal)**:
    ```bash
    sudo dnf install zsh
    ```

## Set as Default Shell

```bash
chsh -s $(which zsh)
```
