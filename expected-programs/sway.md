# sway

`sway` is an i3-compatible Wayland compositor. It serves as the primary tiling window manager.

## Installation

*   **Debian/Ubuntu/gLinux**:
    ```bash
    sudo apt install sway
    ```
*   **Fedora**:
    ```bash
    sudo dnf install sway
    ```
*   **Arch Linux**:
    ```bash
    sudo pacman -S sway
    ```
