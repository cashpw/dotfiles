# rofi / rofi-wayland

`rofi` is an application launcher, window switcher, and dmenu replacement (with native Wayland support via `rofi-wayland` on Fedora/gLinux).

## Installation

*   **Debian / gLinux (Work)**:
    ```bash
    sudo apt install rofi
    ```
*   **Fedora (Personal)**:
    ```bash
    sudo dnf install rofi-wayland
    ```
