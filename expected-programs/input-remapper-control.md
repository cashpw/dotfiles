# input-remapper-control (input-remapper)

`input-remapper` (CLI: `input-remapper-control`) is an input key mapping tool for Linux/Wayland.

## Installation

*   **Debian / gLinux (Work)**:
    ```bash
    sudo apt install input-remapper
    ```
*   **Fedora (Personal)**:
    ```bash
    sudo dnf install input-remapper
    ```
