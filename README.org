#+title: Dotfiles

Personal dotfiles and system configurations for Wayland/Sway desktop environment, Doom Emacs, Zsh, and development tools.

* Installation

#+begin_src sh
git clone git@github.com:cashpw/dotfiles.git ~/.config/dotfiles
cd ~/.config/dotfiles
git submodule update --init --recursive
bash check_programs.sh
#+end_src

* Wayland / Sway Environment Setup

** 1. Install Required Packages

*** Debian / gLinux (Work)
#+begin_src sh
sudo apt update && sudo apt install -y \
  sway swaylock swayidle sway-notification-center mako-notifier kanshi \
  grim slurp wl-clipboard rofi brightnessctl playerctl \
  input-remapper wtype fzf unzip font-manager btop network-manager-tui \
  kitty fcitx5 dunst feh pandoc gnuplot notmuch lieer vlc libreoffice \
  clisp pcre2-utils darktable digikam clinfo
#+end_src

*** Fedora (Personal)
#+begin_src sh
sudo dnf install -y \
  sway swaylock swayidle SwayNotificationCenter mako kanshi \
  grim slurp wl-clipboard rofi brightnessctl playerctl \
  input-remapper wtype fzf unzip font-manager btop NetworkManager-tui \
  kitty fcitx5 dunst feh pandoc gnuplot notmuch vlc libreoffice \
  clisp pcre-tools darktable digikam clinfo
#+end_src

*** Build / Cargo & Custom Tools
For TUI tools, node management, dictation, AI models, and custom components:
#+begin_src sh
# Cargo binaries
cargo install bluetui ncspot i3status-rs
cargo install --git https://github.com/ammgws/autotiling-rs

# Node Version Manager (NVM)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# Local LLM Runner (Ollama)
curl -fsSL https://ollama.com/install.sh | sh

# Gmail Lieer / gmi (Fedora/Pip fallback)
pip install lieer

# Voice Dictation (Voxtype)
bash scripts/config/install_voxtype.sh

# Wayland Property Inspector (wlprop)
mkdir -p ~/.local/bin
cp ~/third_party/wlprop/wlprop.sh ~/.local/bin/wlprop
chmod +x ~/.local/bin/wlprop
#+end_src

** 2. Environment Variables

Ensure the following environment variables are set (e.g. in =~/.profile= or =~/.zshrc=):
#+begin_src sh
export XDG_CURRENT_DESKTOP=sway
export XDG_SESSION_TYPE=wayland
export MOZ_ENABLE_WAYLAND=1
export QT_QPA_PLATFORM=wayland
#+end_src

** 3. Systemd User Services Setup

Enable user-level systemd target and notification services:
#+begin_src sh
systemctl --user daemon-reload
systemctl --user enable --now sway-session.target
systemctl --user enable --now notify-listener.service
systemctl --user enable --now notify-tunnel.service
#+end_src

** 4. Verification

Verify all expected binaries are installed and accessible in your =$PATH=:
#+begin_src sh
bash check_programs.sh
#+end_src

* Email Setup (Lieer / Notmuch)

Lieer (~gmi~) is used to synchronize Gmail repositories locally into Notmuch-indexed maildirs.

** 1. Create Mail Directories

#+begin_src sh
mkdir -p ~/mail/cashbweaver.gmail
mkdir -p ~/mail/cash.cashpw
#+end_src

** 2. Initialize & Authenticate Accounts

*** Personal Gmail (~cashbweaver.gmail~)
#+begin_src sh
cd ~/mail/cashbweaver.gmail
gmi init
gmi auth
gmi sync
#+end_src

*** Personal Domain (~cash.cashpw~)
#+begin_src sh
cd ~/mail/cash.cashpw
gmi init
gmi auth
gmi sync
#+end_src

** 3. Configure Notmuch Indexer

Run initial Notmuch database setup pointing to your =~/{mail_dir}=:
#+begin_src sh
notmuch setup
notmuch new
#+end_src

** 4. Automatic Mail Syncing

Execute the provided helper scripts or configure them via cron/systemd timers for periodic background mail syncing:
#+begin_src sh
bash scripts/mail/sync_cashbweaver_gmail_email.sh
bash scripts/mail/sync_cash_cashpw_email.sh
# or generic wrapper:
bash scripts/mail/sync_local_email.sh cashbweaver.gmail
#+end_src
